# VEBRAM — Operação

Manual da equipe: quem faz o quê, prompts de cada pessoa, rotina e decisões.

| Onde | O quê |
|---|---|
| `prompts/<Nome>/` | Prompt de cada pessoa, por ferramenta |
| `decisoes.md` | Decisões do Lucas (nome, preços, modelos de mensagem). Vale mais que o prompt |
| `rotina.md` | Reuniões de segunda e sexta e o bloco da semana |
| `AGENTS.md` / `CLAUDE.md` | Instruções que o Codex e o Claude Code leem sozinhos |
| Google Sheets (fora daqui) | Planilha geral: metas, realizado e Painel |

## Como usar
- **Codex ou Claude Code**: abra esta pasta, rode `git pull` e diga quem você é. A IA lê o seu prompt sozinha.
- **Chat (claude.ai ou ChatGPT)**: copie o seu prompt de `prompts/<Nome>/` para as instruções de um Projeto. Quando o prompt mudar, copie de novo.

O código do plugin fica em outro repositório, separado (só Lucas e João).
